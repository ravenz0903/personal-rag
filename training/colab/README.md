## Selection and goals

It is overwhelmingly synthetic pilot data. Public review candidates are excluded unless explicitly reviewed; raw generic tool datasets are not passed to the optimizer. The backend remains responsible for authorization, date resolution, stale-write checks and user approval. Fine-tuning does not fix backend bugs.
